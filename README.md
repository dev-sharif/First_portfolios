# Sharif Ahmed — Developer Portfolio

An award-grade portfolio site for a full-stack web developer. Seven sections,
GSAP + Framer Motion choreography, Lenis smooth scrolling, a working contact
form, and a real case-study route per project.

Built with **Next.js 14 (App Router) · React 18 · TypeScript · Tailwind CSS 3 ·
GSAP 3 + ScrollTrigger · Framer Motion 11 · Lenis** — and **no other runtime
dependencies**. Every image is generated by a script in this repo, so there is
nothing to download and nothing to go stale.

## 2. Setup and run

Requires **Node 18.17+** (developed on Node 22).

```bash
npm install

npm run dev        # http://localhost:3000
npm run build      # production build
npm run start      # serve the production build

npm run typecheck  # tsc --noEmit
npm run lint       # eslint

# regenerate bundled assets (optional — they are committed)
npm run gen:art      # all SVGs in public/images
npm run gen:og       # public/og-image.png
npm run gen:resume   # public/resume.pdf
```

**Environment**

```bash
cp .env.example .env.local
# NEXT_PUBLIC_SITE_URL=https://your-domain.com   ← canonical / OG / sitemap origin
```

## 3. Customising

### 3.1 Content — one file

`src/data/portfolio.ts` is the single source of truth. No component hard-codes
a name, link, number or paragraph.

```ts
siteConfig       // name, role, rotating hero roles, tagline, email, socials, résumé paths
navSections      // navbar items + section ids (must match each <section id="…">)
socials          // GitHub / LinkedIn / X / Email
about            // eyebrow, heading, two bio paragraphs, portrait path
stats            // the four animated counters
skillGroups      // Front-end / Back-end / Database / DevOps, each with 0–100 levels
marqueeTechs     // the infinite ticker under the skills grid
projects         // the 6 case studies — add an object and the card, the filter
                 // count, the sitemap entry and /projects/<slug> all appear
projectCategories// filter tabs (labels + counts are derived)
timeline         // experience + education entries
testimonials     // quotes, avatars, star ratings
contactCopy      // contact headline + subject dropdown options
```

### 3.2 Colours, spacing, radii

All tokens are CSS custom properties in `src/app/globals.css`:

```css
:root, [data-theme='dark'] {
  --bg: 8 8 11;         /* space-separated RGB, so Tailwind's
                           rgb(var(--bg) / <alpha-value>) works → bg-bg/50 */
  --accent: 139 92 246; /* electric violet */
  --s-1 … --s-12;       /* 8px spacing system */
  --r-sm … --r-2xl;     /* radii */
  --ease-out-expo;      /* shared motion language */
}
[data-theme='light'] { /* same variable names, different values */ }
```

**Change the accent** — edit `--accent` and `--accent-2` in *both* blocks. One
edit repaints buttons, links, rings, glows, the custom cursor, the typing caret,
the progress bar and the particle canvas (which reads `--accent` live through a
`MutationObserver`). Neon lime, for example:

```css
--accent: 168 255 60;
--accent-2: 190 242 100;
```

Type scale, radii, spacing and easing live in the same block and in
`tailwind.config.ts`.

### 3.3 Fonts

```tsx
// src/app/layout.tsx
const display = Space_Grotesk({ …, variable: '--font-display' });
const body    = Inter({ …,           variable: '--font-body' });
```

Swap in any `next/font/google` family (Syne, Clash Display, Geist, Instrument
Sans…). Self-hosted at build time — no runtime request, no layout shift.

### 3.4 Animation

| What | Where | How to tune |
|---|---|---|
| Global easing + durations | `src/lib/gsap.ts` | `EASE.*`, `DURATION.*` |
| Section reveals | `useScrollReveal` + `[data-reveal]` | `DURATION.slow`, stagger attr, `start` |
| Text split | `ui/SplitText.tsx` | `stagger`, `duration`, `split="chars\|words\|lines"` |
| Timeline spine | `sections/Experience.tsx` | the `scrub` ScrollTrigger on the line |
| Hero parallax | `sections/Hero.tsx` | the `scrub` timeline values |
| Carousel speed | `sections/Testimonials.tsx` | `AUTOPLAY_MS` |
| Preloader timing | `effects/Preloader.tsx` | the `1500` floor and `3200` failsafe |
| Marquee speed | `ui/Marquee.tsx` | `duration` prop |
| Cursor states | `effects/CustomCursor.tsx` | the `data-cursor` attribute switch |

**Reveal markup** (used throughout the sections):

```tsx
<div data-reveal-group data-reveal-stagger="0.08">
  <p data-reveal>…</p>                    {/* fade + rise */}
  <p data-reveal="fade">…</p>              {/* fade only */}
  <p data-reveal="left" data-reveal-delay="0.2">…</p>
  <div data-reveal="clip">…</div>         {/* clip-path mask */}
</div>
```

### 3.5 Images

Replace any file in `public/images/` keeping the name and aspect ratio, or point
the data file elsewhere:

```ts
about.photo.src      // portrait     800×1000 (4:5)
project.image        // thumbnail   1200×820 (≈16:11)
testimonial.avatar   // avatar       160×160 square
```

Cards and the modal use plain `<img loading="lazy" decoding="async">` because the
bundled artwork is SVG; move to `next/image` if you switch to raster files.

### 3.6 Contact form

`src/app/api/contact/route.ts` validates server-side, traps bots with a honeypot
and rate-limits to 5 posts/minute/IP. Deliveries are logged. To receive real
mail, install [Resend](https://resend.com) and uncomment the marked block:

```bash
npm i resend
# .env.local
RESEND_API_KEY=re_xxx
CONTACT_TO_EMAIL=you@example.com
```

### 3.7 Social card

`npm run gen:og` renders `public/og-image.png` from `scripts/generate-og.mjs`
- gradient, grid and monogram drawn pixel by pixel through a hand-rolled PNG
encoder (zlib + CRC32 only). Drop in your own 1200x630 PNG and nothing else
changes.

## 4. Accessibility & performance notes

- **Motion** - every animation checks `prefers-reduced-motion`. Lenis is never
  instantiated, the custom cursor and particle canvas stay off, split text and
  counters render in their final state, the preloader self-skips, and a global
  CSS guard neutralises decorative animation.
- **Keyboard** - visible focus rings, a skip link, Esc-closable modal and mobile
  menu with focus return, a focus trap inside the dialog, arrow-key carousel, and
  real buttons for every dotted control.
- **Semantics** - one `<h1>`, ordered headings, `<dl>` for stats, `<ol>` for the
  timeline, `aria-current` on the active nav item and filter, `aria-live` on the
  form status, decorative nodes `aria-hidden`.
- **Split text & counters** - the animated copy is `aria-hidden` with an
  `.sr-only` duplicate, so assistive tech reads clean prose and the final number.
- **Performance** - animations touch only `transform`/`opacity`; `will-change` is
  applied sparingly; the particle rAF pauses off-screen and when the tab is
  hidden; all ScrollTriggers share the GSAP ticker; fonts are self-hosted; images
  are SVG and lazy-loaded.

## 5. Known trade-offs

- **Tech icons are abstract geometric glyphs**, not trademarked brand logos - they
  inherit `currentColor`, cost ~0 KB and stay visually consistent. Swap any entry
  in `src/components/icons/TechIcons.tsx` for an official SVG.
- **The pinned horizontal project gallery is not included.** A scrubbed pinned
  rail and a filterable grid fight each other for scroll ownership, so the filter
  + 3D tilt grid won. To add one, build it as a separate section with a
  `pin: true, scrub: 1` ScrollTrigger driving an `xPercent` track - the same
  shape as the timeline spine.
- **`/api/contact` runs on the Edge runtime**, so the rate-limit map is
  per-instance. Fine for a single region; swap to a shared store (Upstash) for a
  global deployment.

## 7. Deploying

### 7.1 Two build targets

| Command | Output | Needs a server? | Use for |
|---|---|---|---|
| `npm run build` | `.next/` + Node server | Yes | Vercel, Netlify, Cloudflare, Railway |
| `npm run build:static` | `out/` (pure files) | No | **Surge.sh**, GitHub Pages, S3, any nginx docroot |

`build:static` sets `output: 'export'`, which refuses any dynamic route. Since
`POST /api/contact` is dynamic by definition, the script parks
`src/app/api/contact` outside the router for the duration of the build and
restores it in a `finally` - a crashed build can never leave the repo without
its API route.

URLs come out directory-index style (`/projects/nebula-analytics/index.html`)
via `trailingSlash: true`, which is exactly what Surge serves.

### 7.2 The contact form on a static host

There is no server to run the route handler, so the form falls back to a
prefilled `mailto:` compose instead of showing a dead error. The visitor sees a
distinct "Check your email app" state explaining they still have to hit send.
Detected on a `404`/`405` response or a network failure - no build flag needed,
so the same code works on both targets.

### 7.3 Deploying to Surge

```bash
npm run build:static
npm run deploy            # surge ./out --domain sharif-ahmed.surge.sh
```

The domain is set in two places - `package.json` -> `surge.domain` and the
`deploy` script. To use a different name, change both.

**First run needs a Surge account** (`surge.sh` prompts for email + password
once, then stores a token in `~/.surge`). For CI or a non-interactive machine,
generate a token at surge.sh and set:

```bash
SURGE_TOKEN=<your-token> npm run deploy
```

Always bake the real origin into the build so canonical/OG/sitemap URLs are
correct - a mismatch here is the single most common SEO bug on static hosts:

```bash
NEXT_PUBLIC_SITE_URL=https://your-domain.com npm run build:static
```
